How your key is stored

Keys are encrypted before they are written to the database, using a secret derived from this app's SECRET_KEY. That protects a copied database file or a backup. It does not protect a key from someone who already has access to this server, since the secret lives there too — so keep the machine itself secure.

Only admins and owners can open this page. Saved keys are never displayed again, only the first and last four characters. If SECRET_KEY ever changes, saved keys can no longer be read and must be entered again.
